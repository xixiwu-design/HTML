¿Qué es HTML?

21 de enero de 2026

HTML, abreviatura de Lenguaje de Marcado de Hipertexto, es el lenguaje fundamental para crear páginas web. Su función no es la programación, sino describir la estructura y el contenido de una página web. Podemos pensar en HTML como el esqueleto de una página web: encabezados, párrafos, imágenes, listas y enlaces están definidos y organizados por HTML.

HTML consta de una serie de etiquetas, cada una con una función específica. Estas etiquetas indican al navegador si un contenido es un encabezado, un párrafo o una imagen. El navegador interpreta estas etiquetas para presentar el contenido de la página web al usuario.

Además de definir la estructura, HTML puede añadir información adicional mediante atributos, como indicar el origen de una imagen o el destino de un enlace. Aunque HTML no controla el estilo ni el comportamiento de una página web, es la base de CSS (estilos) y JavaScript (interacciones).

En pocas palabras, sin HTML no existen las páginas web. HTML define la estructura básica, mientras que CSS y JavaScript hacen que la página sea atractiva y dinámica. Comprender HTML es el primer paso en el desarrollo front-end y una parte clave del diseño web.
